# Surge 模块（Luna 维护）

在 Surge 中通过链接安装：模块 → 安装新模块 → 粘贴文件的 raw 地址。
脚本本体指向原作者仓库，作者更新脚本后自动生效；作者若改动文件名/结构，Luna 会同步更新这里的模块文件。

## 扫描全能王 · 每日抽奖签到

- 安装地址：https://raw.githubusercontent.com/Alexanderzhen/corsapi1/main/surge-modules/camscanner.sgmodule
- 脚本作者：MaYIHEI（https://github.com/MaYIHEI/paperclip/tree/main/app/camscanner）
- 用法：装好模块 → 打开扫描全能王 App 任意页停留几秒抓取 Token → 每日 10:15 自动抽奖，成功/失效均有通知。
